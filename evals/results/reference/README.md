# Curated evaluation references

Only intentionally cited, compact summaries belong in this directory. Raw
predictions, provider telemetry, live response caches, checkpoints, and
timestamped run directories stay ignored under `evals/results/`.

Reference summaries must name the dataset revision/checksum, split and
population, retrieval configuration, model/provider mode, metrics, and known
limitations. They are evidence for reproducibility and scope, not a claim
that a small fixture run generalizes to production or to all multi-agent
architectures.
